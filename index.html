How this SCADA-style dashboard works

MATLAB simulates the physical LV grid, then uploads saved stable-window measurements to three ThingSpeak channels. This page reads only public channel feeds, selects an individual run and pairs records by window/event ID, automatically refreshes every 30 seconds, and can be hosted as a static website (e.g. GitHub Pages). It is cloud playback, not live solver streaming; it contains no actuator controls and no Write API keys.
